## Current behavior

## Code locations

## Constraints

## Decisions and reasoning

stated reasons and considered alternatives; leave unknown reasons unknown.

## Verification

Record the date, command or procedure, observed outcome, code revision when
available, and material gaps. Keep implementation, testing and deployment distinct.

## Ownership

maintainer. Include scope and date. Unknown roles stay unknown; Git authorship
alone does not establish these roles.

## Open questions

## Change history

code or issue/commit references, and verification. Retain explanations of replaced
behavior and mark them historical; the current section describes today's state.
